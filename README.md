# Ova012_Bot

A simple, policy-compliant Telegram utility bot built with Python and `python-telegram-bot`. Designed to run 24/7 on Railway with minimal configuration.

---

## 📌 Features

- `/start` – Welcome message
- `/help` – List of available commands
- `/about` – Short description of the bot
- Lightweight, fast, and easy to deploy
- Fully compliant with Telegram Bot API and Telegram Ads policies
